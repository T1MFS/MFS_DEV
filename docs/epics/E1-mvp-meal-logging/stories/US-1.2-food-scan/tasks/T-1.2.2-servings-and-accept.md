# T-1.2.2 Choose servings and accept

[← US-1.2](../README.md) · [Epic E1](../../../README.md)

**As a** user, **I want** to set how many servings I ate and accept the product **so that** the app uses my portion.

**Acceptance:** Servings default to the whole package when quantities are known, accept fractional counts, require a positive count, and editing clears the accepted state.

## Subtasks

### ST-1.2.2.1 Default servings from package quantities

**Status:** Done

- **Rule:** default = `product_quantity / serving_quantity`, only when both are positive, finite, and share a `g` or `ml` unit. Otherwise leave empty for manual entry.
- **Where:** `Sources/NutritionScanning.swift`, scan screen in `Sources/MFSApp.swift`.


### ST-1.2.2.2 Accept snapshot and local Tidepool preparation

**Status:** Done

- **Input:** scanned product and a positive servings count.
- **Output:** `AcceptedFood` and `TidepoolPreparedFood` (nutrition JSON plus issues). Nothing is uploaded.
- **Rule:** gram-based servings only; unmapped nutrients stay local. See the mapping table in the [project README](../../../../../../README.md).
- **Tests:** `TidepoolNutritionMappingTests`.
