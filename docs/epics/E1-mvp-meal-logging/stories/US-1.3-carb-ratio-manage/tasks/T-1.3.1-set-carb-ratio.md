# T-1.3.1 Set my carb ratio

[← US-1.3](../README.md) · [Epic E1](../../../README.md)

**As a** user, **I want** to save my carb ratio **so that** it persists across launches.

**Acceptance:** Defaults to 30, rejects nonpositive or nonfinite values, and updating it updates Manage.

## Subtasks

### ST-1.3.1.1 Validate and persist the ratio

**Status:** Done

- **Input:** user-entered number.
- **Output:** saved ratio in `UserDefaults` (default 30); invalid input rejected.
- **Where:** `CarbRatioSettings` in `Sources/NutritionScanning.swift`.
