# T-1.3.2 See carbs per ratio for accepted food

[← US-1.3](../README.md) · [Epic E1](../../../README.md)

**As a** user, **I want** Manage to show selected carbs divided by my ratio **so that** I can compare foods.

**Acceptance:** Total or net carbs selectable; result is unrounded with no dose units; missing source values show unavailable, not zero.

## Subtasks

### ST-1.3.2.1 Total vs net carb selection and calculation

**Status:** Done

- **Input:** accepted food, selection (total or net = total − ½ fiber), saved ratio.
- **Output:** selected carbs ÷ ratio, unrounded; "unavailable" when a source value is missing.
- **Where:** Manage section in `Sources/MFSApp.swift`.
