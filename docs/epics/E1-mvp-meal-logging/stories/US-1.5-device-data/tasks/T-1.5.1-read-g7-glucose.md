# T-1.5.1 Read glucose from a Dexcom G7

[← US-1.5](../README.md) · [Epic E1](../../../README.md)

**As a** user, **I want** MFS to read my G7 glucose **so that** meals can be viewed alongside it.

**Acceptance:** Glucose readings arrive through G7SensorKit's `G7CGMManager`; state persists across launches.

## Subtasks

### ST-1.5.1.1 Host a G7 CGM manager

**Status:** Planned. The `G7SensorKit` framework is already linked and builds in CI.

- **Input:** `G7CGMManager` (plugin identifier from `G7SensorKit`) with a `CGMManagerDelegate` that MFS provides.
- **Output:** glucose samples delivered to the delegate, plus sensor warm-up and finish times.
- **Note:** `G7SensorKit` imports `LoopKit` and `LoopKitUI`; MFS must supply the delegate and storage they expect.


### ST-1.5.1.2 Persist manager raw state

**Status:** Planned

- **Input:** manager `rawState` dictionary, written when the delegate reports a state change.
- **Output:** the same dictionary restored at launch to recreate the manager.
