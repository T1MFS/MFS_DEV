# T-1.6.2 TestFlight release

[← US-1.6](../README.md) · [Epic E1](../../../README.md)

**As a** maintainer, **I want** a manual signed build uploaded to TestFlight **so that** testers get builds the same way Loop users do.

**Acceptance:** Workflows 1–4 run on demand using match signing and an App Store Connect API key.

## Subtasks

### ST-1.6.2.1 Secrets, identifiers and certificates

**Status:** Needs the maintainer's Apple account

- **Secrets:** `TEAMID`, `GH_PAT`, `FASTLANE_KEY_ID`, `FASTLANE_ISSUER_ID`, `FASTLANE_KEY`, `MATCH_PASSWORD`.
- **Repo:** a `<owner>/Match-Secrets` repository for match storage.
- **Run in order:** 1 Validate Secrets, 2 Add Identifiers, 3 Create Certificates.
- **Where:** `.github/workflows/`, lanes `validate_secrets`, `identifiers`, `certs`, `check_and_renew_certificates`, `nuke_certs`.


### ST-1.6.2.2 Build and upload lanes

**Status:** Written, not yet run

- **Where:** workflow `4. Build MFS`, lanes `build_mfs` and `release` in `fastlane/Fastfile`.
- **Behavior:** signs with match, sets bundle ID `com.<TEAMID>.mfs`, bumps the build number from TestFlight, builds the IPA, uploads to TestFlight.
- **Versioning:** Xcode generates the app's version fields from `MARKETING_VERSION` (initially `1.0`) and `CURRENT_PROJECT_VERSION`; the build lane updates the latter from TestFlight.
- **App Store requirements:** the build uses Xcode 26.3 by default and rejects SDKs older than iOS 26. `Sources/Assets.xcassets` supplies the app icon; its editable artwork is `Sources/AppIcon.svg`.
- **Signing:** the lane sets the bundle ID on the MFS target and enables its `MFS_CODE_SIGNING_ALLOWED` setting, without overriding embedded framework bundle IDs.
- **Frameworks:** the app embeds SwiftCharts for LoopKitUI. The workspace `Package.resolved` pins its revision; before upload the build checks the exported app executable's framework search path and required `@rpath` libraries (excluding iOS-provided Swift runtime libraries).
- **Known state:** the `Test` workflow passes on GitHub; this path needs the secrets from [ST-1.6.2.1](#st-1621-secrets-identifiers-and-certificates).
