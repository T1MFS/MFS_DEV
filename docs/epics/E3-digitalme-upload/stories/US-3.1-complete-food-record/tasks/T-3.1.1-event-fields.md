# T-3.1.1 Collect and validate missing event fields

[← US-3.1](../README.md) · [Epic E3](../../../README.md)

**Status:** Planned

- **Needs:** meal, consumption time, brand (optional in source), name; strings 1–100 characters.
- **Rule:** a scan is not evidence of consumption; the user must confirm time and meal.
- **Output:** validated event context, or a list of field errors.
- **Reference:** Tidepool Food schema (see the [project README](../../../../../../README.md)).
