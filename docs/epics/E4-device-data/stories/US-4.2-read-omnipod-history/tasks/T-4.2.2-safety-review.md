# T-4.2.2 Safety review: no delivery commands

[← US-4.2](../README.md) · [Epic E4](../../../README.md)

**Status:** Planned

`OmniPumpManager` exposes insulin-delivery commands: `enactBolus`, `enactTempBasal`, `cancelBolus`, `suspendDelivery`, `resumeDelivery`, `syncBasalRateSchedule`, `syncDeliveryLimits`.

- **Rule:** MFS must not call any of them.
- **Check:** a test or lint step that fails if these symbols appear in `Sources/`, plus a human review before any release that links `OmnipodKit`.
